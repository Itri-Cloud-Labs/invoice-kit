# Invoice Kit for Python

The Python package is planned but not implemented in this phase.

The port will use:

- A Pythonic API with `snake_case` names
- uv for development and dependency locking
- Hatchling as the standards-based build backend
- Independent versioning and publishing on PyPI

Its first implementation milestone will cover document validation, normalization, calculations, and serialization. PDF rendering will follow after those behaviors match the TypeScript package.
